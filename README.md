## 🚀 About me

I build products, not just code. I co-founded **Bi-Siparis**, a multi-vendor e-commerce platform that grew to **100K+ users** with real revenue, shipped it on the App Store and Google Play, and exited before relocating to Canada.

Today I'm the **Web Developer & Project Manager at [LabNeighbour](https://labneighbour.com/)**, a remote robotics lab, where I own both the technical delivery and the product roadmap.

- 🧭 **End-to-end ownership:** from architecture and UI to auth, payments and store releases
- 📱 **Cross-platform:** iOS, Android and Web from a single codebase (Flutter) or React
- 📈 **Product mindset:** I measure success in users, revenue and shipped features
- 🎓 B.S. Software Engineering · Full-Stack Web Development @ CCTB (in progress)
